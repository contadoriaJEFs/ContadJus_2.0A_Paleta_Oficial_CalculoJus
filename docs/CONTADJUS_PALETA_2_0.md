# ContadJus — Paleta oficial 2.0

A identidade visual experimental desta versão usa:

- Navy `#1A3152` — títulos, textos principais, fundos escuros e tabelas.
- Terracota `#B16447` — destaques, CTAs, linhas e detalhes.
- Cream `#FAF9F7` — fundo institucional.
- Branco `#FFFFFF` — conteúdo e áreas de leitura.
- Bege `#F1E9DF` — destaques suaves e alternância visual.

Cores funcionais (por exemplo, estados de alerta, erro e crédito/débito) permanecem independentes da identidade institucional.

Esta alteração é exclusivamente visual: não altera motores, fórmulas, dados ou regras de cálculo.
